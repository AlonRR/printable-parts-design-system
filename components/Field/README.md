A labelled input or select with its help note and its error line, the unit of every form on the page.

Wrap the label text, with the unit in brackets (`Opening width (mm)`), and its `input.ws-input` in one `label.ws-label`. Give the `input` `inputmode="decimal"` for a value that cannot go below zero; for one that can, use a `Stepper`, whose ↓ goes below zero, or without the arrows `type="number"` (the decimal keypad on a phone has no minus sign, D56), `autocomplete="off"`, read "," as a decimal point as well as ".", and an error `span` after it. Put help text in a `.ws-note` directly under the field, never in a placeholder. Mark a bad value with `aria-invalid="true"` and write the reason in the error span (`.ws-error`), so the message does not depend on colour. Keep the error span in the layout when empty so the form does not jump. Link the error and any note to the input with `aria-describedby`, and give the error span `aria-live="polite"`, so a screen reader reads them with the field and hears a new error. A number field (`type="number"` or `inputmode="decimal"`) is at most `--number-field-w` wide: as wide as a number, not as the sidebar.
