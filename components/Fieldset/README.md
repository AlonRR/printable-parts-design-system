Groups the fields of one decision under a legend, so each question on the page has one box.

Use one `fieldset.ws-fieldset` per decision (The opening, The window, Seal). Its `legend` is a short noun phrase. Open with a `.ws-note` that tells the user what to measure or choose, then the fields. Pick-one options use `Choice` (buttons, not radio dots) and sit in a fieldset with a note under any option that needs explaining.
