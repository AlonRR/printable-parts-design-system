The slim top bar of the tool: name, project actions, theme.

Height `header-h` (48px). Left: the tool name (`h1.ws-header__name`, in the `step` style) and, small beside it, the version (`.ws-header__version`). Right, in this order: undo, redo, reset (quiet buttons), Save project, Load project (they act on the whole project), language if any, the "Dark theme" toggle (`aria-pressed`, pressed while the page is dark). Everything after redo goes in `div.ws-header__actions` with `popover`, opened by a `button.ws-header__more` "More…" (`popovertarget`): inline above the breakpoint, a menu under the header below it (D28). The browser gives the menu its expanded state, Esc and light dismiss; no script is needed. Below the breakpoint the name takes the legend size. When the row is tight, at a narrow phone or just above the breakpoint, the name is cut short (its full text stays in the page): the buttons never shrink, scroll or wrap, and nothing in the header clips a focus ring. Everything here acts on the whole project; step controls never go here. Each button has a Nerd Font icon (undo eae2, redo ebb0, reset eb37, save eb4b, load eaf7, theme eac6) before its word; the icon is `aria-hidden` and the word is always there.
