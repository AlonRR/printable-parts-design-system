The slim top bar of the tool: name, project actions, theme.

Height `header-h` (48px). Left: the tool name (`h1.ws-header__name`, in the `step` style) and, small beside it, the version (`.ws-header__version`). Right, in this order: undo, redo, reset (quiet buttons), Save project, Load project (they act on the whole project), language if any, the "Dark theme" toggle (`aria-pressed`, pressed while the page is dark). Everything here acts on the whole project; step controls never go here. Each button has a Nerd Font icon (undo eae2, redo ebb0, reset eb37, save eb4b, load eaf7, theme eac6) before its word; the icon is `aria-hidden` and the word is always there.
