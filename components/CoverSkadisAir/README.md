Cover art for Skådis Air, 960 × 288 px: one board with its rows of slots in `model-board` and `model-board-outline`, the tool's name and one line on what it does. Say "SKÅDIS-compatible", never use IKEA's logo, colours or wordmark.

It is artwork for use outside the tool: the design system's gallery card, the repository's social preview, a README banner. It is drawn at a fixed size and does not reflow, so it is never placed in the tool itself, whose first screen is the workbench and its welcome dialog. For that reason `scripts/check-previews.py` does not check it on the phone.
