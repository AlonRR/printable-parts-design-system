A grid of picture tiles to choose from, instead of a dropdown, when the options are visual.

Use it for panel fills (sealed, grid, hexagon, brick, diamond) and for saved presets. Each tile is a button with `aria-pressed`, a small drawing of the result and a one-word label; four to a row in the sidebar. Put the most common choice first and show the current one with the `action` outline and `action-tint` background. If there are more than about 12, add a "Gallery" button that opens the full set in a dialog.
