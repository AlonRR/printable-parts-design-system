Pick-one options shown as buttons: each has a radio circle; the chosen one is filled with an inverted circle (white, blue centre, extra white ring). Ticks are for multi-select only.

Use it instead of radio dots for any short choice (format, seal, window type, where the unit is). It is a native radio group underneath: wrap the options in `.ws-choice` with `role="radiogroup"` and an `aria-label`, one `label.ws-choice__opt` per option holding an `input.ws-choice__input` (visually hidden) and a `span.ws-choice__face` with the text. The chosen face is filled with `action` and starts with a tick, so the state never relies on colour; the arrow keys move between options. Keep labels to one or two words and at most about four options; more than that becomes a `Gallery` or a select. Always have one chosen by default.
