Action button. Primary fills with `action`; the default is outlined.

Use at most one primary button in view, for the step that finishes the task (Download the pieces). Label it with a verb and, when it opens a dialog, end the label with an ellipsis. A disabled button explains why in a note next to it. Buttons are `type="button"` unless they submit a form. Put a row of buttons in `.ws-actions`; the plan bar (`.ws-plan__actions`) and a dialog's `menu` have their own.
